## 🚀 代表项目

### 🖼️ xImageDuplicateChecker

**面向海量图片的高性能重复图片检测工具**

面向大规模图片库设计，可处理**百万级文件**的重复图片检测与清理。

支持多种检测方式：

`MD5` · `dHash` · `pHash` · `aHash` · 加速图像比较

不仅可以发现完全相同的文件，还可以识别经过缩放、裁剪或修改后的相似图片。

`Python` `Computer Vision` `Image Processing`

---

### 🗄️ OracleSchemaSnapshot

**Oracle 数据库结构快照、差异比较与同步工具**

生成 Oracle Schema 结构快照，即使两个数据库**无法同时连接**，也可以通过快照进行离线结构比较，并自动生成可审核的同步 SQL。

**快照 → 比较 → 审核 → 生成 SQL**

适用于开发、生产、客户现场以及数据库处于不同隔离网络等场景。

`Python` `Oracle` `Schema Compare` `Database DevOps`

---

### 📐 DrawingContrast

**AI 辅助工程图纸差异分析工具**

比较两个版本的工程 PDF 图纸，并自动识别：

* 尺寸变化
* 标注变化
* 几何结构变化
* 工程信息变化

结合传统计算机视觉与多模态 AI，不仅发现**哪里发生变化**，还尝试理解**发生了什么变化**。

`Python` `OpenCV` `PDF` `Multimodal AI` `Engineering`

---

### 🧹 OracleArchiveManager

**面向 Oracle 大表的安全历史数据归档工具**

为 Oracle 大表历史数据提供可控的归档流程：

**分析 → 复制 → 校验 → 人工确认 → 清理**

重点考虑生产数据库的数据安全。危险操作需要明确确认，并对整个归档过程进行审计记录。

`Python` `Oracle 11g+` `Data Archiving` `Database Maintenance`

---

### 📺 DataVision

**让 Android TV 变成稳定运行的数据看板**

一个用于将 Android TV 转变为全屏数据展示终端的轻量级方案。

支持 Kiosk 模式、网络异常恢复、4K DPI 适配以及自动更新等功能。

`Kotlin` `Android TV` `Digital Signage`
